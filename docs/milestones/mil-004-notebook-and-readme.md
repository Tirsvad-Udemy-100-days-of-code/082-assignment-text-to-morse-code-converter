## Purpose

Decides whether S02 and S03 can understand and run the project: a Jupyter notebook that follows the lecture steps, one screenshot of the program per lecture step and a README from the framework template.

## Deliverable

The notebook `notebooks/Text_to_Morse_Code_Converter.ipynb`, four step screenshots in `docs/images/` generated by a script from the program's own output run in a Docker container (Linux), and the README with overview, requirements, set-up, run, test, Doxygen and the screenshots.

The lecture steps are the ones of the Day 82 lecture list, which has two items: the lecture "The Road to Becoming a Professional Developer" and the assignment. The lecture is summarised in words, never copied or screenshotted. The assignment is split into three steps, so the four steps are: 1 The Road to Becoming a Professional Developer (the set-up of the project), 2 The Morse table, 3 Convert text to Morse code, 4 Run it from the command line.
