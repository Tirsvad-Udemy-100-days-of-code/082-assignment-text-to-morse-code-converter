# Text to Morse Code Converter

Day 82 of Udemy's *100 Days of Code*: a text-based Python program that converts a string into Morse code. This wiki explains what each step teaches. Every step has a screenshot of the program's own output, made in a Docker container from the code.

The lecture, *The Road to Becoming a Professional Developer*, is only summarised here: build projects without a guide, break an idea into small steps, look things up when you are stuck, and keep going until it works.

The assignment is one sentence, so the function names `text_to_morse` and `MORSE_CODE_DICT` follow the solutions that other course participants share. Words are separated by ` / `, and a character without Morse code is rejected.
